# Changelog

All notable changes to DriveLens are listed here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-09

First public release.

### Added

- **Fast scan:** a parallel scan of any local drive, usually under a minute.
- **Dashboard:** free and used space, drive health, a clickable treemap, a top-folders pie chart and a details panel.
- **File Explorer actions:** right-click any item to open it, show it in its parent folder, or copy its path.
- **Detection rules:** finds caches and build output from browsers, npm, pip, uv, Yarn, pnpm, Gradle, NuGet, Cargo, Bun, Hugging Face, Ollama, Docker, `node_modules`, Python environments, Terraform and frameworks such as Next.js.
- **Cleanup guide:** steps with current sizes, copy-ready commands and Disk Cleanup advice.
- **Rescan:** rescan from the dashboard without restarting the tool.
- **Any drive:** run it from any drive, or scan another one with `-Drive`.
- **Light and dark mode.**
