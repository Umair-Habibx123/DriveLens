Cleanup steps

This tool never deletes anything. You run each step yourself, and deleting can't be undone. Skip anything you're unsure about.

Empty the Recycle Bin

Check nothing important is in it. Then right-click its icon and choose Empty Recycle Bin.

Run Disk Cleanup

  1. Press Win + R, type cleanmgr and press Enter, then choose this drive.
  2. Click Clean up system files and choose the drive again.
  3. Tick options one by one using the table below, then click OK and Delete Files.

Clear browser caches

In each browser, press Ctrl + Shift + Delete, choose All time, tick only Cached images and files, then clear. Leave cookies, passwords and history unticked.

Clear Windows Update downloads (optional)

        
Make sure no update is installing and no restart is pending. Then paste this into PowerShell as administrator.

        
Stop-Service wuauserv, bits -Force
Remove-Item "$env:windir\SoftwareDistribution\Download\*" -Recurse -Force -ErrorAction SilentlyContinue
Start-Service wuauserv, bits

Don't delete these by hand

        
    
          
  • Windows folders: anything else in Windows, including Prefetch and WinSxS. Clearing Prefetch gains almost nothing and can slow app launches.
    • 
          
  • System files: pagefile.sys and hiberfil.sys. Use powercfg /h off as administrator to remove the hibernation file; this also turns off Hibernate and Fast Startup.
    • 
          
  • Installer caches: ProgramData\Package Cache, which Windows and Visual Studio use to repair and uninstall software.
    •

How to use it

    
    
      
  1. Double-click DriveLens. For fuller results, right-click it and choose Run as administrator.
    2. 
      
  2. On Overview, click a box to see its details, and double-click a folder to look inside it.
    3. 
      
  3. Right-click any box to open it in File Explorer, where you can delete what you don't need.
    4. 
      
  4. On Clean up, follow the steps you want, then click Rescan.
    5. 
    

    
Shortcuts

    

      ClickSelect a box and show its details

Use it on another drive

    
Copy the whole DriveLens folder to that drive and run it from there. It always scans the drive it's on.

    
About this scan

    
    
      
  • 
      
  • 
      
  • Windows shares some files between folders, so Windows folders can look larger than the space they really use.
    • 
      
  • Drive health is what Windows reports, not a full disk test.
    • 
      
  • It doesn't look for duplicate files or leftover folders from uninstalled software.
    • 
      
  • This page lists your folder names, so check it before sharing it with anyone.
